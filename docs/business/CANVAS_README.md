# لوحة نموذج العمل — ورشتك

نسخة عربية من Business Model Canvas بالخانات التسع، مخصصة لنموذج عمل ورشتك المقترح. المحتوى مستند إلى [نموذج العمل الكامل](../../BUSINESS_MODEL.md)، وليس إلى أسعار مفعّلة أو شراكات أو نتائج تشخيص مثبتة.

- [الصورة عالية الدقة PNG](business-model-canvas-ar.png): مناسبة للعرض والمشاركة.
- [ملف PDF بحجم A3 أفقي](business-model-canvas-ar.pdf): صفحة واحدة للطباعة.
- [المصدر القابل للتعديل HTML](business-model-canvas-ar.html): افتحه في المتصفح أو عدّل النص والتصميم في VS Code.

لا تُضاف هذه المسودة إلى شاشة العميل أو بوابة دفع. الأسعار بالريال السعودي ومقترحة للاختبار فقط، قبل الضريبة. اشتراك الورشة ومساحات الموظفين ضمن الخطة التجارية، وليست مزايا مدفوعة منفّذة في التطبيق.

## إعادة التصدير

من جذر المشروع، باستخدام Playwright/Chromium المتوفرين في بيئة التطوير:

```sh
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright node scripts/export_business_canvas.cjs
```

يمكن تحديد `CHROMIUM_PATH` ومسار Playwright المناسبين لجهاز آخر. يحتاج العرض خط Noto Sans Arabic أو خطًا عربيًا مناسبًا. لا تتطلب اللوحة خدمة API أو مفاتيح أو تغيير تبعيات التطبيق.

تتحقق أداة التصدير من وجود تسع خانات وعدم تجاوز النص حدودها. الملف المصدر مستقل ولا يحمّل خطوطًا أو سكربتات خارجية. صورة PNG مصدرة بدقة مضاعفة، وملف PDF مصدّر بواسطة Chromium مع ألوان وخطوط عربية.
